# Gestión de Proyectos

Material de la materia Project Management (Máster en PM, EGCI Escuela de Gerencia) de Valeria Yashan, basado en PMBOK 8.

## Contenido

- `planificador-ti/app/`: Planificador TI, versión pública (cronograma, ruta crítica, línea base, EVM, reservas, tablero, exportación para Power BI).
- `planificador-ti/alumnos-d0f4dda780e1/`: versión para alumnos, con los cinco casos del Trabajo Integrador y el informe de ejemplo en Power BI (`informe-ejemplo-power-bi.pdf`), que es el dashboard con datos ficticios del proyecto vacaenergia.
- `scripts/`: calibración de costos contra el presupuesto del acta y armado de los casos públicos.

## Uso local

Es una herramienta estática en JavaScript sin dependencias de compilación. Servir la carpeta `planificador-ti/` con cualquier servidor de archivos, por ejemplo `python3 -m http.server`, y abrir `app/index.html` o `alumnos-d0f4dda780e1/index.html`.
